# React Card Component

A simple and reusable card component built using **React.js and Vite**. The project dynamically renders cards using an array of objects passed through props.

## Features
- Reusable React Card Component
- Dynamic card rendering using `map()`
- Data passed through props
- Gradient borders
- Responsive grid layout
- Custom images, titles, and descriptions

## Technologies Used
- React.js
- Vite
- JavaScript
- CSS3

## Installation & Setup

1. Clone the repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project folder:
   ```bash
   cd my-card-project
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

## Project Structure

```text
src/
├── App.jsx
├── App.css
├── Card.jsx
├── Card.css
├── index.css
└── main.jsx
```

## How It Works

Card details are stored in an array of objects and passed to a reusable `Card` component using props. The `map()` method dynamically renders all cards.
